# Session start

- Read `PROGRESS.md` first, before doing anything else. It tracks the phase plan, current
  progress, environment state, and decisions made so far. Update it after every meaningful step,
  not just at the end of a session.

# Git workflow

- After completing a logical chunk of work, create a clean, well-described local commit, then push it to `origin/main` on GitHub automatically — no need to ask before each commit/push.
- One commit per logical change (feature/fix/refactor), not one giant commit per session.
- Still never use destructive git operations (force-push, reset --hard, etc.) without explicit confirmation.
